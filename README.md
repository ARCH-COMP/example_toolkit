# ARCH-COMP tool skeleton

Minimal starting point for an ARCH-COMP tool submission: the required scripts
(`install_tool.sh`, `prepare_instance.sh`, `run_instance.sh`) with argument parsing in
place and `TODO`s for your logic. A tool targets one category (AFF, NLN, AINNCS, …).

See the toolkit info page for the submission pipeline, the script contract, and the
results-file format: <https://arch.repeatability.cps.cit.tum.de/toolkit/info>
